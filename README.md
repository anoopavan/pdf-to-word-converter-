PDF to Word Converter

This project is a simple desktop application that converts PDF files into editable Word documents. It is built using Python and provides a graphical user interface so that users can perform the conversion without using the command line.

The application uses the pdf2docx library to extract content from PDF files and convert it into .docx format. A Tkinter-based interface allows the user to select a PDF file from their system and choose where to save the converted Word document.

When the user clicks the convert button, the application processes the PDF page by page and generates a Word file that preserves the original text layout as much as possible. Status messages are shown to indicate whether the conversion was successful or if an error occurred.

This project demonstrates practical usage of Python libraries, handling external dependencies, and building a simple GUI-based utility application. It can be useful for students and professionals who need quick PDF-to-Word conversions without relying on online tools.
